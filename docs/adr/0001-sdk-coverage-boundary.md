# Cover the documented Kite Connect v3 capabilities

The unofficial Swift SDK will cover every documented REST endpoint, WebSocket market data and order updates, and helpers for validating incoming postbacks. Publisher browser integrations will receive integration guidance; the SDK will not implement a browser plugin.

The [Kite Connect v3 documentation](https://kite.trade/docs/connect/v3/) is the coverage authority. Official SDKs are implementation references rather than endpoint checklists, because their coverage can differ from the current documentation.
