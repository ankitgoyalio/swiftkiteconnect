# Require complete documented coverage for version 1.0

Version 1.0 requires the entire agreed SDK scope, a documentation-to-implementation coverage checklist, automated protocol tests across supported platforms, and usage documentation. Earlier 0.x releases may have partial coverage if their limitations are clearly documented.

Routine tests will use fixtures and controlled transports. Credentialed, read-only smoke tests may be optional; live trading is not required to run the test suite.

Each release will identify the reviewed Kite v3 documentation snapshot and provide an endpoint/capability checklist. Completeness is measured against that snapshot; newly documented capabilities enter subsequent releases, and known gaps remain visible.
